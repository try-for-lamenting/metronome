Usage notes, feature guides, and iOS installation.
Basic Usage

The tempo may be set by dragging the wheel, using the arrow controls, tapping the BPM number for keypad entry, or using the tap function. The time signature controls the number of beats per measure and the note value for each beat.

Subdivisions

In the subdivisions interface, each subdivision tracks divide one beat into equal parts. The individual subdivisions in a beat may be individually accented, and multiple tracks can be used to layer different divisions for polyrhythms. This method is more flexible for creating complex rhythmic patterns than traditional metronomes.

Automator

The automator stores automated tempo patterns that can be useful during practice sessions. The number of measures and tempo changes may be configured. Each measure is determined by the time signature.

Tuner and Reference Tones

The tuner can listen through the microphone or play fixed reference tones. The frequency of A4 is adjustable to different instruments, and the reference section may be used to match pitch without using the microphone tuner.

Timers

Timers count down in the timer page. They can continue while the app is in the background, and when a timer ends the app will signal with an alert sound and notification.

Data Tools

The export and import functions may be used to save configurations such as automator sessions, configuration presets, and timers. Reload can be used to restart the interface and audio engine.
